# TLC

Сайт для будущего языка программирования роботов. Главный экран позволяет выбрать LEGO SPIKE Prime или EV3, создать и открыть проект. В редакторе уже есть точечная доска, раскрывающееся меню и пустой блок: его можно поставить в любое место, перемещать и удалить. Доску можно двигать и масштабировать. Положение блоков сохраняется в браузере и в экспортируемом файле проекта. Проекты можно переименовывать, удалять, экспортировать и импортировать.

Кнопка Bluetooth в редакторе пока показывает состояние этой функции: подключение хаба и выполнение программ нового языка будут добавлены позже. Для прежнего управления SPIKE сохранён отдельный пульт.

Управление Pybricks и блочная программа собираются в редакторе проекта. Пробный режим и подключение хаба доступны на той же странице. Сценарии проверки описаны в [specs/004-controller-block-program/quickstart.md](specs/004-controller-block-program/quickstart.md).

## Локальный запуск

```sh
npm start
```

Откройте `http://localhost:8080/`. Для проверок: `npm test`, `npm run test:hub`, `npm run test:full`.

## Проекты

Версия формата файла — `1`, расширение экспорта — `.robotproj.json`. Структура: `version`, `id`, `name`, `hub` (`spike` или `ev3`), `createdAt`, `updatedAt`, `devices`, `workspace`. Сейчас `workspace.blocks` хранит список пустых блоков с координатами. Импорт создаёт копию с новым идентификатором.

## Блок движения

Добавьте «Движение мотора» на доску, выберите порт, направление, значение и единицу: обороты мотора, градусы мотора или секунды. Обороты относятся к валу мотора без учёта передачи. Направление вращения зависит от установки мотора. Скорость сейчас 360°/с, после каждого действия мотор тормозит. Пустые блоки не выполняются; блоки движения выполняются по положению сверху вниз (при одинаковой высоте — слева направо). Через «Программа Pybricks» можно скачать `.py`, загрузить его в Pybricks Code и запустить на хабе. Подключение и запуск из редактора ещё не реализованы.


## Связанные моторы

Блок «Связанные моторы» задаёт два разных моторных порта и отдельное направление каждого мотора. Общие модули «Скорость» (°/с), «Мощность» (%) и «Величина движения» присоединяются справа. Скорость и мощность — альтернативные режимы. Мощность доступна только с секундами. Для запуска нужен модуль величины движения.

Моторы запускаются друг за другом без ожидания завершения первого, затем программа ожидает завершения обоих. Время общее, обороты/градусы задаются для каждого вала. Это совместный запуск, а не DriveBase с коррекцией курса: прямолинейность зависит от сборки и направлений моторов. При ошибке во время действия программа пытается затормозить оба мотора. На EV3 используется API Pybricks 2 (`control.done`), на SPIKE — `done`. Новые блоки поддерживают сохранение и экспорт проекта.

## Цепочки и листы

Поднесите верх блока к низу другого (в пределах 36 единиц доски): цель подсвечивается, после отпускания блок прикрепляется. Перемещение верхнего блока переносит всю цепочку ниже. Перетаскивание среднего отделяет нижнюю часть цепочки; кнопка ↗ явно отсоединяет её. Можно вставить цепочку между связанными блоками. При удалении среднего блока соседние соединяются. Номера показывают шаги внутри цепочки.

Сначала выполняется вся цепочка сверху вниз, затем следующая цепочка по положению её верхнего блока (сверху вниз, при равной высоте — слева направо). Пустые блоки пропускаются. Порядок добавления параметров мотора на выполнение не влияет.

Вкладки листов находятся внизу, как в таблицах: + создаёт лист, ✎ переименовывает, × удаляет после подтверждения. Последний лист удалить нельзя. У каждого листа свои блоки, цепочки и положение доски. Проекты старого формата открываются на листе «Основная». Импорт/экспорт проекта сохраняет все листы; экспорт Python берёт только активный лист. Листы пока служат именованными пространствами для организации программы: вызовы листов, параметры методов, классы и экземпляры ещё не реализованы.
