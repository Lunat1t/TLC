# Robot Studio

Сайт для будущего языка программирования роботов. Сейчас готов главный экран: выбор LEGO SPIKE Prime или EV3, создание и список проектов, переименование, удаление, экспорт и импорт файлов проектов. Проекты сохраняются в браузере на этом устройстве; для переноса используйте «Скачать файл» и «Открыть файл». Редактор и выполнение программ нового языка будут добавлены позднее.

Прежний телефонный пульт Socer сохранён по адресу `/controller.html`. Его устройство, программа хаба, протокол связи и проверки описаны в [docs/legacy-controller.md](docs/legacy-controller.md).

## Локальный запуск

```sh
npm start
```

Откройте `http://localhost:8080/`. Для проверок: `npm test`, `npm run test:hub`, `npm run test:full`.

## Проекты

Версия формата файла — `1`, расширение экспорта — `.robotproj.json`. Структура: `version`, `id`, `name`, `hub` (`spike` или `ev3`), `createdAt`, `updatedAt`, `devices`, `workspace`. Последние два поля оставлены для будущего редактора. Импорт создаёт копию с новым идентификатором.
