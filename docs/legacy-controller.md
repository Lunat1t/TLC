# Прежний телефонный пульт Socer

Документ описывает сохранённую реализацию, чтобы её можно было использовать и переносить в новый язык. Пульт открыт по `/controller.html`; главный экран Robot Studio открыт по `/`.

## Что делает

Телефон в горизонтальном положении управляет роботом LEGO SPIKE Prime через Bluefy и Web Bluetooth. Один стик задаёт движение вперёд/назад и поворот; L1/R1 переключают 35/60/100% максимальной скорости прямого хода. Кнопка удара посылает отдельную команду, поэтому удар можно запросить во время движения. Скорость стика передаётся при изменении положения и периодически для поддержания связи. Vercel раздаёт файлы сайта; команды идут напрямую между телефоном и хабом.

Для полного робота: A и D — ходовые моторы, F — кикер, E — датчик цвета. Вариант `one_motor_A.py` предназначен только для проверки одного мотора A. EV3 этой реализацией пульта не поддерживается.

## Где код

| Файл | Назначение |
| --- | --- |
| `dist/controller.html`, `dist/style.css` | интерфейс телефона |
| `dist/app.js`, `dist/control.js` | состояние пульта и преобразование стика в команды |
| `dist/pybricks-protocol.js`, `dist/pybricks-config.js` | соединение и обмен с Pybricks |
| `dist/notifications.js` | сообщения о состоянии связи |
| `dist/socer_full.py` | программа полного робота A/D/F/E |
| `dist/one_motor_A.py` | программа для проверки мотора A |
| `dist/check_motor_ports.py` | диагностика устройств в портах |
| `legacy/socer_v10_original.py` | сохранённый исходник из Socer.zip |
| `legacy/stock-web/` | более ранний вариант для штатной прошивки |

## Как запускать прежний пульт

1. Установите прошивку Pybricks на SPIKE Prime через [Pybricks Code](https://code.pybricks.com/).
2. Подключите нужные устройства к портам. Для полного робота запустите `check_motor_ports.py` и убедитесь, что A, D, E, F обнаружены.
3. Загрузите `socer_full.py` в хаб через Pybricks Code. Для проверки с одним мотором используйте `one_motor_A.py`.
4. Остановите программу и отключите Pybricks Code от Bluetooth хаба.
5. Откройте HTTPS-страницу `/controller.html` в Bluefy на iPhone и нажмите «Подключить и играть». При первом запуске держите колёса поднятыми.

Программа полного робота сохраняет управление `DriveBase`, коррекцию прямого хода по энкодерам, поиск жёлтой метки кикера, дозарядку 140° и ограничения времени/угла. Сглаживание команд в текущей версии снято; нулевая команда тормозит. Полная программа объявляет пределы 600 мм/с и 240°/с. Указанные проценты относятся к команде скорости, а не к электрической мощности мотора. Реальная скорость зависит от передачи, нагрузки и питания.

## Связь и остановка

Пульт ищет сервис Pybricks `c5f50001-8280-46da-89f4-6d8051e4aeef`; команды пишутся в характеристику `c5f50002-8280-46da-89f4-6d8051e4aeef` как `WRITE_STDIN` (код 6). Хаб отвечает уведомлениями `WRITE_STDOUT` (код 1). Профиль требует версию не ниже 1.3. Текстовая команда движения имеет вид `v,скорость,поворот,удар`; `k` посылает удар отдельно, `x` останавливает, `h` запрашивает готовность. Смотрите [профиль BLE Pybricks](https://github.com/pybricks/technical-info/blob/master/pybricks-ble-profile.md).

В полной программе пауза команд дольше 350 мс начинает замедление, а после 1200 мс моторы тормозят. Для одного мотора таймаут 600 мс. Кнопка «СТОП» тормозит сразу. После потери связи движение необходимо запустить снова.

## Что проверялось

Проверки `npm test`, `npm run test:hub`, `npm run test:full` покрывают преобразование стика, протокол и логику программ. Пользователь подтвердил обнаружение A/D/F/E, запуск `socer_full.py` с `SOCER_READY|A,D,F,-1,1,1`, а ранее — движение мотора A из Bluefy. Движение полного робота и кикер требуют отдельной проверки на собранной машине.
