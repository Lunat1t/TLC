# Камера телефона в блоке «Дисплей»

## Подключение на публичном сайте

1. Подключите устройство с редактором и телефон к одной сети Wi-Fi.
2. На [Brick Studio](https://techlabcode.vercel.app/) войдите в аккаунт, добавьте «Дисплей» в область «Управление» и нажмите «Подключить телефон».
3. Отсканируйте QR штатной камерой телефона, откройте ссылку и нажмите «Включить камеру». Вход на телефоне и установка сертификата для публичного сайта не требуются.

Для обмена параметрами соединения нужен интернет. Видео передаётся напрямую между устройствами без звука. Целевое качество — 720p и до 32 кадров/с, фактическое зависит от камеры, браузера и сети. Гостевая сеть с изоляцией клиентов может блокировать прямую передачу.

## Локальный запуск

На компьютере с OpenSSL выполните:

```sh
npm run dev:lan
```

Откройте адрес HTTPS, который напечатает скрипт. Если у компьютера несколько сетевых интерфейсов, задайте IPv4 Wi-Fi вручную через `npm run dev:lan -- --host <IPv4 компьютера>`. Порт по умолчанию — 3443. На гостевой сети с изоляцией клиентов телефон может не видеть компьютер.

### Первый запуск на устройствах

Камера в мобильном браузере требует доверенного HTTPS. Скрипт создаёт собственный локальный удостоверяющий центр и печатает пути к открытым файлам для установки. [Доступ браузера к камере](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia).

- **iPhone или iPad.** Перенесите `BrickStudio-LAN.mobileconfig` на устройство, установите профиль в «Настройки → Основные → VPN и управление устройством». Затем включите доверие к Brick Studio Local Display в «Основные → Об этом устройстве → Доверие сертификатам». [Инструкция Apple](https://support.apple.com/ru-ru/102390).
- **Android.** Перенесите `rootCA.cer` и установите его как сертификат центра сертификации в настройках безопасности и хранилища учётных данных. Названия пунктов зависят от устройства.
- **Компьютер с редактором.** Доверьте `rootCA.cer` в хранилище корневых сертификатов, которым пользуется браузер. Переносите на устройства только открытый сертификат или профиль. Закрытый ключ остаётся в частной папке компьютера.

### Подключение

HTTPS-адрес использует отдельное хранилище браузера. Войдите в Brick Studio на этом адресе. Чтобы продолжить уже начатый проект с прежнего адреса, выберите проект на рабочем столе, нажмите «Скачать файл», затем на HTTPS-адресе выберите «Открыть файл проекта».

В редакторе добавьте «Дисплей», откройте его QR и отсканируйте штатной камерой телефона. Перейдите по ссылке и разрешите доступ к камере. Видео идёт напрямую между браузерами через WebRTC, звука нет. Целевые настройки — 720p и до 32 кадров в секунду. Реальный режим зависит от камеры, браузера и сети.

Сигнальные сессии живут в памяти локального сервера. Используйте HTTPS-адрес из этого запуска и в редакторе, и на телефоне. Сеанс завершается кнопкой остановки, закрытием блока или перезапуском сервера.
