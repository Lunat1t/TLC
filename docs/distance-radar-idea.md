# Идея: Сонар-рябь и угловой радар для датчика расстояния

- **Статус:** Идея / backlog (зафиксировано 2026-11-23)
- **Референс:** `https://21st.dev/@21st/components/dot-field-drops` (Dot Field Ripples — компонент написан для Remotion; в приложении реализуется лёгким React + `<canvas>` без зависимости от Remotion)

## Что уже есть в проекте
- В [`src/components/editor/robot-session.tsx`](../src/components/editor/robot-session.tsx) и виджете `distance-gauge` в [`src/components/editor/control-area.tsx`](../src/components/editor/control-area.tsx) уже приходит поток `sensorDistances[port]` (`0..200 см` и `null` для `>200 см`), а без робота доступен ползунок симуляции.
- **Физическое ограничение датчика:** ультразвуковой датчик EV3 / SPIKE Prime измеряет только одно значение дистанции вперёд по лучу, без угла азимута.

## V1: Сонар-рябь в виджете `distance-gauge` (без правки BLE-протокола)
- **Макет карточки (`>= 160×112`):** сверху остаётся выбор порта и крупное значение (`см`); основную часть (`flex-1`) занимает тёмное `<canvas>`-поле точек (`#0f172a`), хорошо контрастирующее со светлым пультом.
- **Состояния по дистанции:**
  - `< 15 см` — частая быстрая рябь, крупные красные точки (`#ef4444`);
  - `15–45 см` — умеренные янтарные волны (`#f59e0b`);
  - `46–200 см` — плавные изумрудно-бирюзовые волны (`#10b981` / `#22d3ee`);
  - `> 200 см` / `--` — спокойная тусклая сетка.
- **Симуляция без робота:** ползунок `0..200 см` выносится компактно **под** `<canvas>`, не заменяя саму визуализацию сонара.
- **Производительность и доступность:** статичный кадр в режиме редактирования (`editing`), при скрытой вкладке (`document.hidden`) и при `prefers-reduced-motion`.
- **Ограничение при реализации:** перед правками сохранить существующие незакоммиченные изменения пользователя в `src/components/editor/*`.

## V2: Угловой секторный радар (будущее развитие)
