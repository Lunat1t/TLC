# Controller contracts

## HTTP

`GET /api/controller-layout`: `{config, updatedAt}` или 401. `PUT /api/controller-layout` принимает `{config}` и возвращает тот же объект. Сервер проверяет версию, количество элементов, порты, скорости, координаты и строки. Ошибки: 400, 401, 500. Запросы с cookie сессии; Supabase Auth обновляет metadata текущего пользователя.

## BLE stdin

После `SOCER2_READY|<ports>` пульт отправляет `h\n` для проверки и строки `m,<port>,<speed>\n` для изменения скорости мотора в градусах/с. `x\n` тормозит моторы. Хаб отвечает `SOCER2_ACK` и повторяет `SOCER2_READY|...` на `h`. Каждая команда ограничена 100 байтами. Пульт посылает heartbeat каждые 150 мс. Хаб тормозит все моторы при отсутствии команд 600 мс.

## Экран

Подключение вызывает системный выбор Bluetooth; отдельная кнопка запуска отправляет команду запуска установленной программы. Пара даёт противоположные скорости до отпускания. Одиночная кнопка даёт выбранное направление до отпускания; замок фиксирует вращение до повторного нажатия, стопа или потери связи. Для одного порта действует последнее действие.
