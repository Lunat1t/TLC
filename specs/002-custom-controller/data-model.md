# Data Model

## ControllerLayout

Поля `controller_layout` и `controller_layout_updated_at` в `auth.users.user_metadata`. Next API читает и изменяет их только через проверенную сессию ученика.

## Config v1

`version: 1`, `hub` из списка совместимых Powered Up хабов, `gamepad` с портами левого и правого приводных моторов и отдельным необязательным портом действия, и `ports` с настройками скорости 0–100% и реверса. Ранее сохранённое поле `controls` принимается для миграции старых раскладок, но новые команды используют назначение `gamepad`. Замок и координаты стиков — временное состояние, не сохраняются.

## Состояния

Bluetooth: disconnected → connected → starting → ready → stopped/disconnected. Движение разрешено только в ready. Открытие редактора, скрытие страницы, потеря фокуса, отключение и стоп сбрасывают временные команды и замки.
