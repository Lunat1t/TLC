# Quickstart validation

1. Открыть сайт по HTTPS и войти как ученик.
2. Назначить два порта привода и отдельный порт действия; изменить скорости; перезагрузить страницу и войти на втором устройстве. Ожидаются те же назначения без активного замка.
3. Выполнить `npm test`, `npx tsc --noEmit`, `npm run build`. `npm test` включает симуляцию программы хаба и проверки таймаута.
4. Скачать программу из пульта, загрузить её в совместимый хаб через Pybricks Code и отключить Pybricks Code от Bluetooth.
5. Нажать «Подключить Bluetooth», выбрать хаб с произвольным именем, затем «Запустить программу». До READY кнопки не включают мотор.
6. Проверить кнопки вперёд/назад и повороты, отдельные стрелки мотора действия, замок, независимые скорости, стоп, скрытие вкладки и разрыв Bluetooth. При последних трёх действиях моторы должны остановиться. Аппаратную проверку выполнять с поднятыми колёсами.

## Временный пустой пульт

- Поле управления оставлено пустым по запросу. Верхняя панель содержит подключение, запуск, настройки, стоп и отключение после подключения.
- Конфигурация хаба, модулей и сохранение остаются в `public/controller.js` и `public/controller-model.js`; служебные DOM-узлы скрыты в `public/controller.html`. Кнопка скачивания программы находится в окне настройки.
- Бывшие стрелки работали через наборы `drivePressed` и `actionPressed`, `recompute()` смешивает скорость левого/правого привода и задаёт направление мотору действия. `releaseAll()` очищает команды и замок. Для возврата видимого управления восстановить элементы `.drive-arrow`, `.action-arrow` и `#actionLock` в пустой области.
- Кнопка установки приложения перенесена на главную страницу. PWA-манифест запускает `/`, а service worker не кэширует команды робота.

Production `dpl_44HysY2sL86LLSarAXvVaq1FBxSz` проверен в браузере на основном домене: поле пустое, сверху четыре действия и статус, установка доступна на главной, редактор модулей и скачивание программы открываются через «Настроить».
