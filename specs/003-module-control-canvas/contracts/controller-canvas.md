# Контракт поля управления модулями

## Видимый интерфейс

| Действие | Результат |
| --- | --- |
| «Настроить» сверху | все моторы остановлены; слева открыта панель устройств, поле остаётся видимым; начинается черновик размещения |
| «+» в панели | отдельное окно выбора: привод 2/4 мотора, мотор, группа моторов; недоступный тип выключен и объясняет причину |
| Выбрать доступный тип | выбор закрывается; устройство и один связанный блок появляются сразу; панель остаётся открытой |
| Поменять порт или удалить карточку | изменение видно в связанном блоке; конфликт порта не допускается; удаление убирает блок |
| Настроить скорость или реверс порта в левой панели | новое значение сохраняется вместе с модулем после галочки и применяется к соответствующему мотору |
| Тянуть за область заголовка блока | блок следует за указателем только в пределах поля; `pointercancel`/потеря захвата возвращает позицию до жеста |
| Фокус на заголовке, клавиши стрелок | блок перемещается небольшим шагом; `Shift` + стрелка — крупным шагом; поля выбора порта сохраняют своё стандартное поведение |
| «Готово ✓» | валидирует черновик, сохраняет, закрывает панель и фиксирует блоки; при ошибке показывает короткое сообщение и остаётся в размещении |
| Закрыть или `Escape` | отменяет черновик и возвращает последнюю подтверждённую раскладку |
| Нажать моторную стрелку в рабочем режиме | движение только назначенных портов соответствующего блока, пока удерживается кнопка; `Стоп` сбрасывает все блоки и замки |

На телефоне панель является выдвижной, с затемнением поля и доступной кнопкой закрытия. После выбора модуля окно выбора закрывается, а панель может быть свёрнута, чтобы ученик разместил новый блок; режим `editing` остаётся активным до галочки или отмены. Поле не прокручивается горизонтально. В режиме `editing` все органы управления моторами отключены.

Контраст, видимый фокус и подписи `aria-label` обязательны. «+», галочка, закрытие и управление блоками доступны клавиатурой. Замок вращения отдельного мотора имеет `aria-pressed`; галочка размещения не является этим замком.

## Конфигурация и API

Действующий `GET /api/controller-layout` возвращает `{config, updatedAt}` и `PUT /api/controller-layout` принимает `{config}`. Только авторизованный ученик читает и изменяет собственную конфигурацию; ошибки и `401` сохраняют существующий контракт. `Cache-Control: private, no-store` остаётся.

Новая часть `config`:

```json
{
  "version": 1,
  "devices": [
    {"id": "drive", "type": "drivetrain", "name": "Привод", "leftPorts": ["A"], "rightPorts": ["D"]},
    {"id": "arm", "type": "motor", "name": "Подъём", "ports": ["B"]}
  ],
  "moduleLayout": [
    {"deviceId": "drive", "x": 0.08, "y": 0.34},
    {"deviceId": "arm", "x": 0.72, "y": 0.34}
  ]
}
```

Пример показывает расширение, а не полный `ControllerConfig`: поля `hub`, `ports`, `gamepad` и `controls` продолжают присутствовать в полной записи. Сервер проверяет `moduleLayout` и возвращает его в канонической конфигурации. Старый ввод без этого поля принимается и нормализуется; произвольные дополнительные поля не сохраняются. Ключ локальной копии остаётся `tlc.controller-layout.v1`, чтобы не потерять прошлые назначения.

Координаты должны быть конечными числами 0…1; идентификаторы должны соответствовать устройствам 1:1. Критические ошибки в `deviceId`, портах или числах дают `400` для PUT. Для старой схемы без координат миграция создаёт позиции; клиент и сервер используют одинаковое правило.

## Моторные команды

Протокол хаба не меняется. Браузер рассчитывает выходы по активным направлениям каждого `device.id` и собирает одну команду скоростей портов через существующий `commandFor`. Привод смешивает ход и поворот для левой/правой стороны; группа выдаёт одинаковое направление двум портам с индивидуальной скоростью/реверсом. Одновременные блоки не конфликтуют, потому что порт уникален. Команды не отправляются до READY или в `editing`.

Вход в настройки, смена порта/хаба, стоп, скрытие страницы, потеря соединения и ошибка передачи обнуляют все выходы и замки. Программа хаба сама тормозит при отсутствии команд дольше существующего таймаута 600 мс. Никакое сохранённое состояние не может автоматически возобновить вращение после перезагрузки.
