# Проверка поля управления модулями

## Подготовка

Из корня `socer-web` запустить `npm install` при первом использовании, затем `npm run dev`. Открыть `http://localhost:3000/controller.html` для проверки размещения. Для Web Bluetooth и установленного приложения использовать опубликованный HTTPS адрес и совместимый хаб с Pybricks. Проверки моторных команд проводить с поднятыми колёсами.

## Сценарий 1 — добавление и размещение

1. Открыть «Настроить». Ожидается левая панель с карточками модулей; поле остаётся видимым.
2. Нажать «+». Ожидается отдельное окно выбора. Выбрать «Мотор»; окно закрывается, в панели появляется карточка порта, а на поле — новый блок со стрелками и замком.
3. Переместить блок мышью или пальцем к краю. Блок остаётся целиком внутри границы. Отменить другой жест через `pointercancel` или Escape; позиция до жеста восстанавливается.
4. Сфокусировать заголовок блока и переместить его клавишами стрелок. Поля выбора портов при фокусе используют стандартные клавиши выбора.
5. Нажать «Готово ✓». Панель закрывается, блок не двигается от перетаскивания. Перезагрузить страницу: позиция и порты сохранены. Снова открыть настройки: перемещение доступно.
6. Передвинуть блок и закрыть панель без галочки. После повторного открытия видна последняя подтверждённая позиция.

## Сценарий 2 — ограничения и перенос старых данных

1. Открыть ранее сохранённую конфигурацию без `moduleLayout`. Ожидается по одному блоку для каждого старого устройства; порты, скорости и реверс не изменились.
2. Попробовать добавить второй привод и модуль при нехватке свободных портов. Оба варианта недоступны с коротким объяснением.
3. В двух карточках попробовать выбрать один порт. Конфликт не сохраняется. Удалить модуль: соответствующий блок исчезает; остальные остаются.
4. Войти в аккаунт, подтвердить раскладку, обновить страницу и открыть её на другом авторизованном устройстве. Позиции и устройства совпадают. Без входа показывается состояние локальной копии, а не обещание облачного сохранения.
5. Установить мобильную ширину около 390 px. Панель выдвигается, поле не имеет горизонтальной прокрутки, все блоки доступны по вертикали.

## Сценарий 3 — управление и безопасность

1. Без хаба нажать на блок: мотор не запускается. При размещении блоков стрелки также не посылают команд.
2. Загрузить программу с сайта через «Настроить» в Pybricks Code, отключить Pybricks Code от Bluetooth, подключить хаб с произвольным именем и отдельно нажать «Старт». До READY блоки отключены.
3. После READY проверить привод и два независимых моторных блока. Группа вращает оба назначенных порта; скорость и реверс каждого порта соблюдаются. Отпускание стрелки останавливает мотор без замка.
4. Включить замок у одного моторного блока. Проверить, что другой блок независим. Нажать «Стоп», открыть настройки, скрыть вкладку и разорвать Bluetooth по отдельности: каждый случай останавливает все моторы и сбрасывает замки.

## Команды проверки перед выпуском

Запустить `npm test`, `npx tsc --noEmit`, `npm run build` и `git diff --check`. Затем проверить обе ширины в браузере и опубликованный `/controller.html` на основном домене. Браузерная сборка подтверждает интерфейс и схему; направление моторов и потерю радиосвязи подтверждает только проверка на хабе.

Формат данных и переходы описаны в [data-model.md](data-model.md), а поведение интерфейса и API — в [contracts/controller-canvas.md](contracts/controller-canvas.md).
