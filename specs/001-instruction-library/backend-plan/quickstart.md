# Проверка бэкенда TLC

Подготовить отдельные тестовые Supabase и папку Drive, разрешённый PDF, администратора и четырёх учеников, два планшета для одного ученика. Проверить историю миграций и зависимости согласно `supabase/migrations/README.md`; настроить серверные переменные по `docs/instruction-library-setup.md`, не передавая ключи в чат или Git.

1. `npm install`, `npx tsc --noEmit`, `npm test`, `npm run build`; затем `npm run dev`. Главная, её CSS и JS возвращают 200, dev/build не перезаписывают общий кэш одновременно.
2. Проверить фактический проект и Data API до и после миграций: каталог возвращает 200 и тестовые карточки; документы недоступны гостю.
3. Проверить вход, обновление истекшей сессии, выход, отказ роли и недоступность базы; cookies обновляются, ошибки различимы.
4. Преподаватель загружает PDF через простую форму в закрытую папку Drive; Supabase хранит только черновик и метаданные закреплённой ревизии. Проверить дубликат/повтор, отозванный доступ, отсутствие папки, размер и недоступность Drive.
5. Доказать доступность закреплённой ревизии после изменения PDF, удержание до конца запуска, восстановление и реакцию на удаление; без этого gate неизменяемости остаётся открытым.
6. После реализации занятий проверить четыре учётные записи, адресный запуск, повторный запрос, замену планшета, потерю сети и восстановление прогресса. Гость, другой ученик и старый планшет не получают материалы через TLC и прямой Data API.
7. Проверить PDF и Range на планшете, закрытие запуска и отказ доступа после закрытия. Результаты и размеры записать в `docs/instruction-library-validation.md` без секретов.

8. Проверить PDF на границе 100 000 000 и 100 000 001 байт: первый допускается, второй отклоняется с сохранением черновика. Проверить память сервера и потоковую выдачу без загрузки всего файла.
9. На главном экране открыть библиотеку кнопкой и свайпом; проверить клавиатуру, доступные подписи и отсутствие случайного переключения при прокрутке. Проверить отдельные страницы PDF, вперёд/назад, сохранение страницы после обновления, потери сети и смены планшета. При отсутствии связи показать сообщение, после восстановления продолжить сохранённый запуск.
