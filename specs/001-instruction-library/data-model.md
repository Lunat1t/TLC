# Data model: библиотека инструкций TLC

Модель описывает первую версию для SPIKE Prime и EV3. Идентификаторы — UUID; адресный `slug` уникален и после публикации стабилен. В базе хранятся ключи файлов, не публичные URL.

## Instruction

| Field | Meaning | Rule |
| --- | --- | --- |
| id | Постоянная идентичность | UUID, ключ |
| slug | Адрес страницы | уникальный, не меняется при переименовании |
| title, summary | Название и описание | обязательны для публикации |
| kit | SPIKE Prime или EV3 | обязательный контролируемый список |
| topics | Темы поиска | нормализованный список коротких меток |
| status | `draft`, `published`, `archived` | в публичном каталоге только `published`; шаги не публичны |
| cover_asset_id | Обложка | необязательна, заглушка в UI |
| rights_attested_by, rights_attested_at | Подтверждение права | обязательны для публикации |
| published_at, updated_at | Время | серверное; сортировка каталога |

Переходы: `draft → published → archived`; `archived → published` после проверки материалов. Публикация разрешена только при наличии хотя бы одного шага или документа.

## InstructionStep

`id`, `instruction_id`, `position`, `caption`, `asset_id`. Позиция уникальна внутри инструкции; перестановка выполняется атомарно. Изображение шага обязательно для визуального шага. Шаги и подписи закрыты до адресованного запуска, даже когда карточка опубликована. Изменение инструкции не меняет снимок уже открытой сборки; шаги не удаляют файлы, на которые он ссылается.

## InstructionAsset

`id`, `instruction_id`, `kind` (`cover`, `step_image`, `document`), `object_key`, `mime_type`, `byte_size`, `created_at`. Допускаются только проверенные изображения и PDF в пределах лимита конфигурации. Все объекты находятся в закрытом bucket. Обложка доступна через проверенный маршрут только для опубликованной карточки; изображение шага или PDF — администратору либо ученику с действующим запуском, активным планшетом и ссылкой на файл в неизменяемом снимке запуска. Замена создаёт новый ключ и обновляет ссылку; старый объект удаляется только после проверки отсутствия ссылок из открытых запусков.

## InstructionAdmin

`user_id`, `granted_at`, `granted_by`. Выдаётся владельцем системы доверенным путём; ученик не может создать или изменить запись. Отдельная сущность не зависит от саморедактируемого `profiles`.

## StudentSession

`id`, `student_id`, `auth_session_id`, `generation`, `last_seen_at`, `started_at`, `ended_at`. Не более одного активного сеанса планшета на ученика (частичный уникальный индекс по `student_id` для `ended_at IS NULL`). Новый подтверждённый вход атомарно закрывает старую запись и создаёт новую с большим `generation`; старая вкладка не может реактивировать себя heartbeat-запросом. Онлайн — `ended_at IS NULL` и `last_seen_at` моложе порога активности. Каждый защищённый запрос сверяет пользователя, текущий `auth_session_id` и `generation`; администратор читает только текущий сеанс.

## StudentSelection

`student_id`, `instruction_id`, `selection_version`, `selected_at`, `status` (`awaiting_launch`, `launched`). Одна текущая запись на ученика, а не на планшет. Выбор только опубликованной инструкции; изменение увеличивает версию. Новый выбор во время сборки в одной транзакции сохраняет текущий прогресс, закрывает прежний запуск и ставит новый выбор в `awaiting_launch`.

## AssemblyLaunch

`id`, `student_id`, `created_for_session_id`, `instruction_id`, `selection_version`, `instruction_snapshot`, `admin_id`, `idempotency_key`, `status`, `created_at`, `opened_at`, `ended_at`. Неизменяемый `instruction_snapshot` фиксирует порядок шагов, подписи, документы и ссылки на файлы при запуске. `created_for_session_id` нужен для аудита и проверки исходной команды, но дальнейшее право на открытие определяется текущим сеансом того же ученика: запуск и прогресс переходят на новый планшет. Статусы: `pending → opened → completed/closed`; `pending → superseded` при смене выбора до открытия либо архивации инструкции; `opened → closed` после сохранения прогресса при выборе другой инструкции. Завершение учеником даёт `completed`, обычное закрытие — `closed`; оба состояния видны администратору. Новая команда разрешена лишь при актуальном выборе опубликованной инструкции и текущем сеансе. Идемпотентность по `(admin_id, idempotency_key)`. Запуск переживает краткий обрыв связи и смену планшета.

## AssemblyProgress

`launch_id`, `current_step`, `completed_step_ids`, `version`, `updated_at`. Прогресс принадлежит запуску и ученику, не планшету. Изменение требует текущего поколения сеанса и совпадения `version`, чтобы запоздалый запрос прежнего планшета не перезаписал новый шаг. Шаги сверяются со снимком запуска. Прогресс остаётся после закрытия для истории, но закрытый запуск больше не даёт доступ к защищённым файлам.

## Relationships and privacy

- Instruction 1:N InstructionStep и InstructionAsset.
- StudentSession N:1 ученик во времени; одновременно активен максимум один. StudentSelection 1:1 ученик и N:1 Instruction.
- AssemblyLaunch N:1 ученик, Instruction и администратор; исходный StudentSession сохраняется для аудита; 1:1 AssemblyProgress.
- Публичны только карточки опубликованных инструкций и разрешённые обложки. Шаги, документы, черновики, список учеников, выборы, сеансы и запуски закрыты. Снятая с публикации карточка исчезает немедленно, но ученик с уже открытым запуском продолжает его сохранённый снимок до завершения/закрытия, в том числе на новом планшете.
- Существующую политику публичного чтения `profiles` надо пересмотреть до появления списка учеников; админский список строится через авторизованный серверный запрос.
