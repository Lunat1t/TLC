# Quickstart: проверка программы пульта из блоков

Ссылки: [data-model.md](data-model.md), [contracts/controller-program.md](contracts/controller-program.md).

## Подготовка

```bash
npm install
npm test          # модель, компилятор программы, сервер, симуляция хаба
npm run build
npm run dev       # http://localhost:3000
```

Для аппаратной проверки: SPIKE Prime с Pybricks, мотор на порту A, браузер с Web Bluetooth (HTTPS или localhost).

## Сценарии в браузере

1. **Сборка.** `/editor` → новый проект SPIKE → «Пульт» → «Когда кнопка ▲ нажата» + «Движение мотора» A вперёд без величины; «Когда кнопка ▲ отпущена» + «Стоп мотора» A. Ожидание: блоки примагничиваются, стиль как у «Основные». Попытка вставить «Если» под шапку не подсвечивает слот.
2. **Экспорт не изменился.** Добавить «Когда программа запускается» + мотор 1 оборот → «Программа Pybricks». Ожидание: в коде нет действий из шапок кнопок.
3. **Открыть пульт.** Кнопка «Пульт». Ожидание: открыт `/controller.html?project=<id>`, имя проекта в выборе, нет «Настроить» и панели модулей.
4. **Пробный режим.** Удерживать ▲, отпустить; нажать стрелку ↑ на клавиатуре. Ожидание: подсветка, в ленте «▲ нажата → Мотор A вперёд 360°/с» и «▲ отпущена → Стоп мотора A»; бейдж «Пробный режим»; кнопки без обработчиков приглушены.
5. **Ошибка.** В редакторе сделать вторую шапку «▲ нажата», вернуться и нажать «↻». Ожидание: `#programErrors` показывает дубликат и «Открыть в редакторе»; ▲ не выполняется, остальные кнопки работают.
6. **Мобильная ширина 360 px.** Ожидание: нет горизонтальной прокрутки, кнопки ≥ 44 px, лента под пультом.

## Сценарии с хабом

1. «↓ Программа хаба» → загрузить в Pybricks Code → отключить Pybricks Code.
2. Bluetooth → Старт. Ожидание: «Робот управляется», мотор A крутится, пока держишь ▲, и тормозит при отпускании.
3. Шапка «A нажата» + мотор A 1 оборот + мотор A назад 2 секунды. Ожидание: последовательное выполнение, лента показывает оба шага.
4. Во время вращения: «Стоп» / скрыть вкладку / выключить Bluetooth. Ожидание: мотор остановлен ≤ 600 мс, режим вернулся в пробный.
5. Старая программа хаба (v2) + блок с оборотами. Ожидание: сообщение «Скачай новую программу хаба», непрерывные команды работают.
