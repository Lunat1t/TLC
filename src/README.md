# Веб-приложение TLC

## Overview

В этой папке находятся маршруты Next.js, интерфейс TLC, общая логика проектов и клиентов Supabase.

## Interface

- [Маршруты](./app/README.md) содержат страницы и обработчики HTTP.
- [Компоненты](./components/README.md) содержат интерфейс редактора, каталога, профиля и рабочего стола.
- [Библиотека](./lib/README.md) описывает хранение проектов, блочное программирование, управление хабом и операции с инструкциями.
- [Клиенты Supabase](./utils/README.md) разделяют браузерные, серверные и публичные запросы.
- [`middleware()` и `config`](./middleware.ts) определяют, когда запрос проходит через проверку сессии.

## Invariants

- `middleware()` пропускает API, главную страницу, страницу пробного урока и манифест без обновления сессии. Для остальных подходящих маршрутов он передаёт запрос клиенту Supabase, когда заданы оба параметра подключения.
- `config.matcher` исключает ресурсы Next.js и перечисленные типы статических файлов.

## Side Effects

- Клиент middleware может обновлять cookies сессии и перенаправлять запросы к защищённым страницам. [Реализация клиента](./utils/supabase/middleware.ts)
