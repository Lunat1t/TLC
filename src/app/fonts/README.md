# Local Fonts

Fonts bundled locally for offline and reliable PWA usage without external CDN requests.

- **Onest** (SIL Open Font License 1.1) — основной шрифт интерфейса и заголовков. Variable weight 100–900, Cyrillic + Latin.
- **JetBrains Mono** (SIL Open Font License 1.1) — технические метки: порты A–F, номера деталей, значения. Variable weight 100–800, Cyrillic + Latin.
