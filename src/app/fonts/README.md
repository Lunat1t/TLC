# Nunito

Variable Nunito (weight 200–1000), normal and italic, licensed under SIL OFL 1.1.
Source: https://github.com/google/fonts/tree/main/ofl/nunito

The complete upstream TTF files were converted losslessly to WOFF2 using fontTools.
Both files include Latin, Russian and Kazakh characters. See OFL.txt for licensing.

Loaded locally through next/font/local. The shared --font-ui stack is used by the
application, home screen, lab headings and hub labels; code keeps its monospace font.
