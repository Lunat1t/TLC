# Local Fonts

Fonts bundled locally for offline and reliable PWA usage without external CDN requests.

- **Nunito** (SIL Open Font License 1.1) — основной шрифт интерфейса: мягкий, округлый. Variable weight 200–1000, Cyrillic + Latin.
- **Lora** (SIL Open Font License 1.1) — шрифт заголовков и названий, «страница блокнота». Variable weight 400–700, Cyrillic + Latin.
- **JetBrains Mono** (SIL Open Font License 1.1) — код и программы Pybricks. Variable weight 100–800, Cyrillic + Latin.
