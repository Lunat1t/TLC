# Instruction management APIs

## Overview

Groups publication by Drive link, published card editing and the resumable PDF upload flow.

## Subdirectories & Boundaries

- [Published instruction editing](./[instructionId]/README.md) — Publisher endpoint for reading and updating an existing published instruction.
- [Publish a Drive link](./link/README.md) — Publishes an instruction from a publicly readable Google Drive PDF.
- [Start a Drive upload](./upload/README.md) — Creates the resumable upload session for an instruction PDF.
